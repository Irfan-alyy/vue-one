# My First Vue Project
This is my first project built using Vue 3 with the Composition API. It demonstrates a basic blog system where you can:

📰 View a list of dummy blog posts

➕ Create and add new blog posts

🌐 Navigate between pages using Vue Router

📦 Manage app state with Pinia

# 🛠 Tech Stack
### Vue 3 (Composition API)

### Vue Router

### Pinia

# 🚀 Features
Home page displaying dummy blog posts

Create blog page to add new blog entries

Route-based navigation

Global state management using Pinia

Responsive and clean UI (optionally mention CSS framework if used)
